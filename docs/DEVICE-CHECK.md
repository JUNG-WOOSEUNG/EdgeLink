# 실기기 확인 순서

밤사이 만든 기능 중 실제 Mac·아이폰으로만 확인할 수 있는 것들이에요. 위에서부터 하면 돼요. 결과는 각 줄의 체크칸에 표시하고, 이상하면 어떻게 보였는지 한 줄 적어주세요.

## 준비

```sh
cd ~/Workspace/EdgeLink
./scripts/build-app.sh
open build/EdgeLink.app
```

- 메뉴 막대에 EdgeLink 아이콘이 생겨요. 처음 설정을 이미 끝냈으면 창 없이 메뉴 막대에만 떠요.
- 아이폰은 잠금을 풀고, AssistiveTouch를 켜둬요.
- 처음 켜면 손쉬운 사용·입력 모니터링을 다시 물어볼 수 있어요. 시스템 설정에서 EdgeLink를 켜주세요.
- 문제가 생기면 언제든 **⌃⌥⌘Space**를 누르면 Mac으로 돌아와요. 그래도 안 되면 터미널에서 `pkill EdgeLink`.

## 1. 기본 전환 (가장 중요)

- [ ] 팝오버가 "연결됨 · Mac 조작 중"으로 보인다 (몇 초~20초 걸릴 수 있음)
- [ ] 배치에서 고른 쪽(지금은 화면 왼쪽) 끝의 가운데쯤으로 커서를 꾹 밀면 아이폰으로 넘어간다
- [ ] 넘어가는 동안 화면 끝에 파란 유리 알약이 튀어나온다
- [ ] 넘어간 뒤 Mac 커서가 사라지고, 트랙패드로 아이폰 커서가 움직인다
- [ ] 메뉴 막대 아이콘이 "전파 나오는 아이폰"으로 바뀐다
- [x] Mac 키보드로 아이폰 메모 앱에 글자가 입력된다 (한/영은 Caps Lock) — 2026-10-20 확인. Caps Lock 때 앱이 꺼지던 문제와 ⌃Space를 아이폰이 놓치던 문제를 고친 뒤 정상
- [ ] 아이폰 화면 반대쪽(오른쪽) 끝으로 커서를 밀면 Mac으로 돌아온다
- [ ] 돌아온 Mac 커서 높이가 아이폰 커서 높이와 대충 맞는다 (위치 맞추기 전이라 조금 어긋나도 됨)
- [ ] ⌃⌥⌘Space로 넘어가고 돌아오기
- [ ] 클릭, 드래그, 스크롤(방향이 자연스러운지), 오른쪽 클릭

## 2. 돌아오는 위치 맞추기

- [ ] 설정(팝오버 "설정…" 또는 ⌘,) › 배치 › 위치 맞추기 → 안내대로 아이폰 오른쪽 아래까지 옮기고 클릭
- [ ] 결과 창에 "완료했어요"가 나온다
- [ ] 맞춘 뒤 돌아오는 높이가 더 잘 맞는다
- [ ] 위치 맞추기 후 처음 설정 "연결 확인"의 원이 아이폰 화면 가운데에 더 가깝게 돈다

## 3. 안전장치

- [ ] 아이폰 조작 중 Mac에 비밀번호 창(예: 시스템 설정 › 사용자 잠금 해제)이 뜨면 바로 Mac으로 돌아온다
- [ ] 아이폰 조작 중 ⌃⌘Q(화면 잠금) → Mac으로 돌아와 있다
- [ ] 아이폰 블루투스를 끄면 바로 Mac으로 돌아오고, 눌린 키가 남지 않는다
- [ ] ⌃⌥⌘를 누른 채 넘어갔다 돌아와도 Mac에 수정키가 눌린 채 남지 않는다
- [ ] 아이폰 조작 중 활성 상태 보기에서 EdgeLink를 강제 종료 → Mac 커서가 다시 보이고 움직인다
- [ ] 다시 켜면 정상 상태로 시작한다

## 4. 제스처·미디어 키

- [ ] 설정 › 입력 › 트랙패드 제스처 설정: AssistiveTouch 기기 목록에 이 Mac이 어떤 이름으로 보이는지 (도우미 문구와 같은지)
- [ ] "버튼 4 보내기"를 아이폰이 인식한다 → 앱 전환기 등으로 지정
- [ ] 아이폰 조작 중 세 손가락 위로 쓸기 → 아이폰 앱 전환기 (Mac Mission Control이 먼저 가져가는지도 확인)
- [ ] 대체 단축키 ⌃⌥⌘↑, ⌃⌥⌘H
- [ ] 미디어 키를 아이폰으로 켜고 볼륨 키 → 아이폰 볼륨

## 5. 창과 화면

- [ ] 설정 창이 860×640이고 아래에 빈 띠가 없다, 신호등 버튼 위치
- [ ] 설정 › 입력에서 단축키 기록: Esc 취소, 수정키 없이 누르면 안내, ⌃⌥Space 넣으면 겹침 확인 창 → "그래도 쓰기"
- [ ] 슬라이더·스위치 색이 파랑인지 (캡처에선 회색으로 나왔음)
- [ ] 알약 버튼 양 끝에 세로줄이 없는지 (캡처에서만 생기는 것으로 보임)
- [ ] 클립보드 보내기(⌃⌥⌘V): 확인 창 → 보내는 중 알림 → "보냈어요"
- [ ] 다크 모드로 바꿔서 팝오버·설정·처음 설정 한 번씩

## 6. 연결 관리

- [ ] 팝오버 기기 메뉴 › 연결 끊기 → 다시 연결
- [ ] Mac 잠자기 후 깨우기 → 2초 안에 다시 연결
- [ ] 설정 › 연결 › 연결 로그 보기, 복사하면 주소 뒷자리가 가려진다

## 7. 블루투스 도우미 (v0.3.1)

블루투스는 이제 `EdgeLink.app/Contents/MacOS/edgelink-hid`가 따로 맡아요. 활성 상태 보기에서 "edgelink-hid"가 EdgeLink 아래에 보여요.

- [ ] 새 빌드를 처음 켰을 때 블루투스 권한을 다시 묻지 않는다 (물으면 무엇의 이름으로 묻는지 적어주세요)
- [ ] 연결 로그에 "블루투스 도우미 시작 (pid …)"이 있고, 그 뒤 연결 로그가 전처럼 이어진다
- [ ] 아이폰 블루투스를 끄면 바로 Mac으로 돌아오고, 눌린 키가 남지 않는다
- [ ] 끈 채로 2~3분: 메뉴바 아이콘·팝오버가 멈추지 않는다. `~/Library/Logs/EdgeLink/EdgeLink.log`에 "메인 스레드 멈춤"이 없다
- [ ] 다시 켜면 재연결된다. 안 붙으면 로그에 "블루투스 도우미를 새로 띄워…"가 나오고 그 뒤 붙는지
- [ ] 터미널에서 `pkill -9 edgelink-hid` → Mac으로 돌아오고, 몇 초 안에 도우미가 다시 떠서 재연결된다
- [ ] 아이폰 조작 중 마우스·키 입력 지연이 전과 같다 (빠르게 원 그리기, 드래그, 타이핑)
- [ ] 비밀번호 창이 뜨면 바로 Mac으로 돌아온다 (도우미 분리 뒤에도)
- [ ] 앱을 끝내면 `pgrep edgelink-hid`에 아무것도 안 나온다

## 8. 화면 2차 다듬기 (v0.3.5)

- [ ] 팝오버·설정 창·확인 창의 ⓘ에 마우스를 올리면 말풍선이 뜨고, 치우면 닫힌다 (누르면 열고 닫기)
- [ ] 메뉴 막대 팝오버 안의 ⓘ 말풍선이 팝오버를 닫지 않는다
- [ ] 테두리만 있는 알약 버튼·칩(배치 칩, "건너뛰기", "설정 열기") 양 끝에 세로선이 없다
- [ ] 라이트 모드 팝오버 머리글 앱 아이콘 윤곽이 보인다
- [ ] 업데이트 창 릴리스 설명이 제목·글머리표로 보인다 (다음 업데이트 때)


## 9. 다른 Mac · 외장 모니터 여러 대

준비: 집 Mac의 EdgeLink는 끄거나 잠자기 상태로 둔다 (아이폰은 블루투스 키보드·마우스로 한 번에 Mac 하나에만 붙는다). 새 Mac에서는 [Releases](https://github.com/JUNG-WOOSEUNG/EdgeLink/releases/latest)의 DMG로 설치하고, 막히면 시스템 설정 › 개인정보 보호 및 보안 › "그래도 열기".

- [ ] 처음 설정 › 배치에 모니터 3대(내장 + 외장 2대)가 모두 나오고, 모니터끼리 맞닿은 가장자리는 고를 수 없다
- [x] 외장 모니터(메인이 아닌 모니터)의 가장자리를 골라도 그 가장자리에서 넘어간다 — 2026-10-21 회사 Mac(MacBook + 외장 2대)에서 확인
- [ ] 메인보다 위·왼쪽에 놓인 모니터의 가장자리에서도 넘어간다 (좌표가 음수인 경우)
- [ ] 돌아올 때 고른 모니터의 맞는 높이로 커서가 돌아온다
- [ ] 해상도 배율이 다른 모니터(Retina + 일반)가 섞여도 넘어가기·돌아오기 위치가 맞다
- [ ] 아이폰 조작 중 모니터 케이블을 빼면 Mac으로 돌아오고, 배치가 다시 계산된다
- [ ] 외장 키보드의 한/영 키로 아이폰 한/영이 바뀐다 (v0.3.6: Caps Lock처럼 ⌃Space로 보냄)
- [ ] 외장 마우스: 휠 스크롤 방향·속도, 오른쪽 클릭, 가장자리 밀기 감도
- [ ] 외장 마우스 옆 버튼(뒤로·앞으로)은 그대로 아이폰 버튼 4·5로 간다. 제스처 버튼을 등록했다면 앱 전환기·홈이 열린다
- [ ] 트랙패드 제스처: AssistiveTouch 버튼 등록은 기기(Mac)마다 따로라 새 Mac에서 다시 등록해야 한다
- [ ] 회사 정책(MDM)으로 권한이 막히면 팝오버에 "회사 정책으로 막혀 있을 수 있어요" 안내가 나온다
